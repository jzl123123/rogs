# 算法对齐边界

当前权威基线是官方提交 `0f816c66d06a7680d1b16eb52e9a9f764bc6920c` 的**代码行为**。论文用来解释方法与核查差异；论文描述和代码不一致处不在工程化时偷偷改写。

19 个算法 Python 文件仅将 `datasets/models/utils/evalution` 的导入改为 `rogs.*`，函数、常量、优化参数、渲染与评估计算均保持原状。`tools/verify_algorithm.py` 对每个原文件核验摘要，再规范化导入后的 AST 比较。新增 CLI、配置、数据预检和来源记录在这组文件之外。

GS 只有上游 README 指定的语义构建变体：包名改为 `diff_gs_label`，`NUM_CHANNELS` 从 3 改成 7；GLM 使用上游 gitlink 指向的 `5c46b9c07008ae65cb81ab79cd677ecc1934b903`。C++/CUDA 算法源码不改。RGB、语义来自同一提交，构建器自动完成，不需要人工编辑第三方源。

## 保留的行为

- 规则 XY 网格、最近轨迹点的高度/旋转初始化、默认固定 XY。
- RGB/语义/平滑/Z/depth 损失、权重与归约；语义分支几何 `detach()`。
- 掩码及 nuScenes 原始标签映射、上半幅裁剪、后视车身 mask。
- 每相机曝光补偿、裁剪范围、BEV 分块和原始评估实现。
- 逐场景优化；没有改造成通用网络训练或添加增密路径。

## 已知但暂不修正的问题

| 代码事实 | 本阶段处理 |
|---|---|
| 原版点云加载和语义 mask 是强耦合依赖 | CLI 提前检查所需资源；不实现无标签/无点云新模式 |
| RGB masked loss 乘 mask 后对整幅图取均值 | 保持，另记录有效覆盖用于未来评价改进 |
| 语义特征 softmax 后进入 CrossEntropyLoss，语义不反传几何 | 保持，不将损失替换成另一种实现 |
| GT BEV 颜色保存乘 225，预测乘 255 | 保持，不能一边修一边拿原表比较 |
| opacity 从 inverse_sigmoid(1) 开始，存在无穷 logit | 保持，数值对比承认同符号 inf；不擅自改 epsilon |
| 高度监督和评估的近邻实现不完全相同 | 保持 |
| 原版 checkpoint 恢复调用/格式与最终保存不一致 | 工程入口明确拒绝续训；后续单独修复并验证 |
| README 预处理模块名和 ---save_root 拼写错误 | CLI 调用实际存在的 process_nusc 模块与参数；计算不变 |

## 对齐的三个层次

1. **源码结构一致**：Mac 的 AST 检查可确认，目前已验证。
2. **同环境、同输入的数值一致**：需要 Ubuntu NVIDIA 跑 baseline / train，再 compare_runs；目前未验证。
3. **论文指标一致**：还需要与原论文相同的标签、数据范围、评估协议和环境；目前未验证。

Mask2Former 官方 Mapillary Swin-L semantic 是可用的独立推理配置，不等于已确认 RoMe 的配置。参考复现先使用原标签。相机数、类别数、像素坐标和类别映射不能因工程封装而改变。
